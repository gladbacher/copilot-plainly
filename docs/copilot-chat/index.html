Guide 2

Copilot Chat

The everyday chat. It is the one part of Copilot almost everyone at a Microsoft 365 company already has.

The short version

  • Open it at copilot.cloud.microsoft, in the Edge sidebar, or inside Outlook and Teams, signed in with your work account.
  • Chat It answers from the web. To use a work document you give it that document.
  • Premium It can search your work data for you.
  • Check anything important. It can be wrong, and it can answer differently each time.

Getting in

Copilot Chat is available to people who sign in with a Microsoft Entra work or school account on an eligible Microsoft 365 plan, at no extra cost (Microsoft, 2026e). You can reach it in several places:

  • The Microsoft Copilot app on web, desktop and mobile (copilot.cloud.microsoft)
  • The Copilot icon in the Edge sidebar, when Edge is signed in with your work account
  • Copilot Chat inside Outlook and Teams
Check which account you are in

The app also accepts personal Microsoft accounts. Chats, files and protections are kept separate for each. For work, look for the Work label under your profile and the green data protection shield (Microsoft, 2026e).

Your organisation can turn web search off with the Allow web search in Copilot policy. If it does, Copilot answers from the language model alone (Microsoft, 2026e). That is an organisation setting, not something you can change.

Choosing how it thinks

Copilot has a model selector. The default is Auto, which picks for you (Microsoft, 2026a).

OptionUse it for
AutoMost of the time
Quick responseSimple questions where you want a short answer fast
Think deeperOpen-ended or complex questions where you would rather wait for a more thorough answer

Microsoft notes these options change as new models arrive. Whether models from outside providers, such as Anthropic and OpenAI, appear is an organisation setting.

Four habits that help

  1. Start with the goal. Add context, sources and the format you want only if you need them (Microsoft, 2026c).
  2. Follow up. Microsoft expects you to refine; the first answer is a draft.
  3. Check what matters. Microsoft says responses are not guaranteed to be fully factual and you should review them before sending them to others (Microsoft, 2026d).
  4. Run it twice if it matters. The same prompt can give different results because of built-in randomness (Microsoft, 2026c).

ChatWith Copilot Chat

Giving it your files

Chat cannot search Microsoft Graph, so it does not look through your emails, files and meetings for you. Microsoft says there are three ways to get work content into it (Microsoft, 2026a):

  1. Paste or upload itCopy text into the prompt, upload a file, or select a file when you write the prompt.
  2. Open it firstIn Outlook and Teams, Copilot Chat can see the item you have open, so you do not need to paste it. In Outlook it can also work with your inbox and calendar (see Word and Outlook).
  3. Use an agentPay-as-you-go agents can reach organisational content, if your organisation has turned this on. See Agents.

What to expect

  • The web: when Copilot decides a search would help, it sends a query to Bing and answers with public information (Microsoft, 2026e).
  • Your work data: only what you provide.

PremiumWith M365 Copilot (Premium)

Work data, automatically

The same chat, but Copilot can use your emails, files, meetings, chats and calendar through Microsoft Graph, with no upload needed (Microsoft, 2026a). It also searches the web when it decides that would help.

  • You can name a file to focus on, but you do not have to upload it.
  • It shows you only what you already have at least view permission to open (Microsoft, 2026d). A file you cannot open will not appear.
  • If answers are not using your work context, Work IQ may be switched off for your organisation. That is an organisation setting; see Troubleshooting.
