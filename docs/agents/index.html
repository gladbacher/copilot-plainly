Guide 7 · Agents

Agents: the overview

An agent is Copilot set up for one kind of job. You pick it, then give it the task.

The short version

  • Microsoft ships a set of agents, and you can build your own. This section covers agents in Microsoft 365. It does not cover Copilot Studio.
  • Find agents in the Agents area of the Copilot app, or type @ and pick one.
  • Chat You get agents grounded in instructions and the web. Agents that use work data are pay-as-you-go and must be switched on by your organisation.
  • Premium You also get Researcher, Analyst and agents that can use your email, meetings and files.

What an agent is

Microsoft describes agents as scoped or focused versions of Copilot that act as assistants and can automate processes (Microsoft, 2026a). An agent is a set of instructions, plus optional knowledge sources such as websites or files, plus the tools it may use.

Where to find agents

  • The Agents pane. In the Copilot app, open Agents in the left navigation. Pre-installed agents are listed there (Microsoft, 2026am).
  • All agents / the Agent Store. All agents opens the Agent Store, a hub for agents from Microsoft, partners and your organisation. Choose Add or Open (Microsoft, 2026ag, 2026am). Some agents show Request approval instead of Add (Microsoft, 2026an).
  • @-mentioning. In the Copilot app you can mention an agent in your prompt. Type @ and pick the agent. I couldn't find a Microsoft page that explains the steps, so if it doesn't work for you, use the Agents pane instead (Microsoft, 2026z).
  • Pinning. Agents can be pinned by Microsoft, by administrators and by you. Researcher and Analyst are pinned by default where you have them (Microsoft, 2026ah). Use the pin icon to keep your favourites at the top.
  • Links. A colleague can send you a link to an agent they built (Microsoft, 2026am).

ChatWhich agents you get with Copilot Chat

  • Included: agents grounded in instructions and public websites. Microsoft says these come with Copilot Chat (Microsoft, 2026a, 2026ac).
  • Microsoft's coaching agents (Idea, Writing, Prompt, Career and Learning Coach) are described as included with Copilot Chat at no extra cost (Microsoft, 2026ah). I also found a setup page that suggests at least some of them use credits in a pay-as-you-go tenant, and I couldn't reconcile the two, so treat them as "included, but your organisation must have enabled them" (Microsoft, 2026ae).
  • Pay-as-you-go: agents that use work data such as SharePoint files and Copilot connectors are billed by usage. They are off by default and your organisation has to set them up. That is a billing setting only an administrator can change (Microsoft, 2026ae, 2026ah).
  • Not available on Chat: knowledge from your email, people data, Teams messages and meetings needs a Copilot licence (Microsoft, 2026ac).
  • Researcher and Analyst: Microsoft's pages put these on the licensed side (Microsoft, 2026ar). See Researcher.

How to tell: open the Agents pane. What you see is what your organisation has enabled for you. A missing agent means the licence, or an organisation setting; it is not a fault with your account (Microsoft, 2026n).

PremiumWhich agents you get with M365 Copilot (Premium)

  • Everything in Chat, with no pay-as-you-go step for the work data a licence already covers.
  • Researcher and Analyst: advanced agents that Microsoft lists on the licensed side (Microsoft, 2026ar, 2026ah). See Researcher and Analyst.
  • Agents that use your email, people, Teams messages and meetings as knowledge (Microsoft, 2026ac).
  • Agents you build can use those same sources. See Make your own agent.

Your administrator can still switch individual agents off. Researcher and Analyst sit in the core chat experience and may not fall under agent-blocking settings (Microsoft, 2026ad).
