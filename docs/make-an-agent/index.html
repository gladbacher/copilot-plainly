Agents · Build

Make your own agent

Two ways to build one without code: Agent Builder in the Copilot app, and agents in SharePoint.

The short version

  • Agent Builder (New agent in the Copilot app): describe what you want, or fill in the Configure tab yourself.
  • SharePoint agents: create one from a library, list or selected files, scoped to that content.
  • An agent only shows people knowledge they could already open.
  • What you can use as knowledge depends on your tier. See Chat and Premium.
  • Agent Builder can't take actions in other systems. Copilot Studio can, and is outside this guide.

Agent Builder: Describe or Configure

Open the Copilot app, choose New agent. Agent Builder isn't available on mobile. You have three ways in:

  1. Describe (recommended): chat about what you want. It fills in the name, description, instructions, knowledge and starter prompts for you, and you can see them on the Configure tab.
  2. Skip to configure: fill in the fields yourself.
  3. Templates.

Natural-language Describe works only in the languages Microsoft lists; otherwise use Configure.

Do I have it?

Look for New agent in your Copilot app. If it is there, you can build. Microsoft's pages differ on whether Chat users get it without pay-as-you-go, so your own app is the answer.

Writing good instructions

The Configure tab has these fields, with limits:

FieldLimit
Name30 characters
Description1,000 characters; also used to decide when to use the agent
Instructions8,000 characters
Starter promptsA name and a prompt each; no minimum number

A template for instructions that works for most agents:

Instruction template
Role: You are [role] for [team/audience].
Purpose: Help people with [the jobs it should do].
Use only: [the knowledge sources]. If the answer isn't there, say "I don't know" and say who to ask.
Format: [short answers / bullets / steps]. Keep a [friendly, plain] tone.
Never: [give legal or HR advice / guess / share personal data].
Always: end with the source you used.

Knowledge sources

Knowledge limits per agent:

  • Public websites: 4 (up to two path levels, no query strings)
  • SharePoint files, folders or sites: 100 files; 1 SharePoint list
  • OneDrive files: 50
  • Files you upload: 20 (not password-protected or certain labelled files)
  • Teams chats: 5 chats and 5 meetings
  • "Only use specified sources" prioritises your sources but does not block general AI knowledge.
  • New SharePoint or OneDrive files can show "Preparing" for several minutes.
  • Web access is blocked if your organisation turns off web search, even if the toggle looks on.

Testing and starter prompts

Use the Try it tab. It becomes available once the agent has a name, description and instructions, and updates as you edit. You can't share prompts, give feedback or @mention other agents in Try it. Test with:

  1. Three questions it should answer well.
  2. One question the sources can't answer. It should say so.
  3. One awkward question that tries to make it break its rules.

Sharing and permissions

  • A new agent is private. The share dialog offers Can edit and Can chat. Groups can only be Can chat.
  • You can copy a chat link or an edit link, or turn on org-wide sharing for chat. When it is on, others in your organisation can see the agent in the Agent Store.
  • Who may share is an organisation setting: all users, specific users or groups, or no one. If sharing is restricted, an administrator must approve and deploy the agent.
  • People only see knowledge they can already open. The agent respects each user's permissions and sensitivity labels, and leaves out files they can't see. Sharing an agent does not share the underlying files. Check the file permissions yourself before you share.
  • People you share with need the licence type the agent's capabilities need; otherwise using it may give an error.

Editing, updating and deleting

  • Open it from All agents and choose edit. Changes save automatically, but users don't see them until you choose Update, which can take a few minutes.
  • I found no version history or roll-back described. Keep your instructions in a separate document so you can restore them.
  • Deleting is permanent and removes the agent for other owners and shared users.
  • You can add an About this agent description, a privacy statement and terms links.

SharePoint agents

An agent in SharePoint answers from a library, list, site or selected files.

  1. Open the library or list, choose Copilot, then Create an agent. Or select files or folders and right-click Create an agent.
  2. Name it, set its scope, and add starter prompts. Editors can add other sites, change branding and edit prompts.
  3. Share by copying the link from the chat pane, or through the file's sharing dialog.
  • You need edit permission on the site, plus a Copilot licence or a tenant with pay-as-you-go for SharePoint agents.
  • All site members can create agents. Agents are .agent files in the site's libraries; deleting the file deletes the agent.
  • Default site agent: each site's own Copilot can't be shared. Site owners choose the main agent under Settings > Site AI. Microsoft says upgrades to agents in SharePoint are coming in mid-November 2026, so this may change.
  • After you use a SharePoint agent it appears in your Agents list in the Copilot app, where you can pin it.

Worked example: a team FAQ agent

  1. Collect the answersPut your team's FAQ, onboarding guide and process documents in one SharePoint folder. Check that the whole team can open it.
  2. Start in Agent BuilderChoose New agent and describe it: "A friendly team assistant that answers questions about how we work, using only our FAQ folder."
  3. Add the folder as knowledgeOn Configure, add the SharePoint folder. Turn on Only use specified sources.
  4. Set the instructionsUse the template above. Add: "If it isn't in the folder, say so and name [team owner]."
  5. Add starter prompts"How do I book leave?", "Who approves purchases?", "Where is the onboarding checklist?"
  6. Test, then shareRun the three tests above. Share with the team as Can chat.

ChatWhat you can use on Copilot Chat

Per Microsoft's licensing table, without usage billing a Copilot Chat agent can use custom instructions, web search, scoped web search, the code interpreter and the image generator. It can't use SharePoint, embedded files or Copilot connectors as knowledge.

With pay-as-you-go switched on by your organisation, it adds SharePoint, embedded files and connectors. Email, people data, Teams messages and meetings still need a Copilot licence.

So a team FAQ agent that reads a SharePoint folder needs pay-as-you-go on the Chat track. Without it, you can build one grounded in public websites and instructions only.

Chat starter
You are a plain-English explainer for [team]. Use only the websites listed as knowledge.
Answer in five lines or fewer, link the page you used, and say "I don't know" if the sites don't say.

PremiumWhat you can use with M365 Copilot (Premium)

All of the knowledge sources in the licensing table are available: SharePoint, embedded files, connectors, and your email, people data, Teams messages and meetings. Email knowledge is your whole mailbox and can't be narrowed, and the people you share with don't get your email. Be careful that an agent grounded in your mail never becomes a way to reveal it; use SharePoint sources for shared agents.

Premium starter
You are the project assistant for [project]. Use the SharePoint folder and the project's Teams meetings as knowledge.
Answer questions on decisions, owners and next steps. Quote the source, and say when the sources are silent.
