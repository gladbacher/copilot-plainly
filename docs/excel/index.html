App guide

Excel

Copilot in Excel can change your workbook, not just talk about it. That makes the mode you pick matter.

The short version

  • There are three modes: Allow editing, Plan and Chat only. Use Plan or Chat only when the file matters.
  • It uses Excel's own features (formulas, charts, PivotTables), so what it makes stays editable.
  • Editing works on Windows, Mac and the web. Phones are chat only for now.
  • Keep a copy before a big multi-step change.

What it can do

According to Microsoft, Copilot in Excel can:

  • Add, rename and delete sheets, change cells and ranges, and apply formatting, validation and layouts.
  • Generate data and formulas across sheets.
  • Create charts, PivotTables and shapes.
  • Answer questions about your data, and sort and filter.
  • Search the web and cite sources.
  • Import data from other workbooks (OneDrive, SharePoint or your computer).
  • Run saved "skills" for repeatable tasks.

Microsoft says it updates your workbook using Excel's built-in features, so the content stays editable. A Stop button lets you halt a task that is running.

The three modes

ModeWhat happensUse it when
Allow editing (default)Handles multi-step tasks and edits the workbook directlyA throwaway file, or you've saved a copy
PlanProposes a plan for you to review before any changeA file other people rely on
Chat onlyAnalyses and answers; does not modify the workbookYou only want an explanation or a formula to copy

The page does not use the phrase "Agent mode"; Microsoft's other pages and blog posts do.

What Microsoft's page doesn't say

What Microsoft doesn't say

The Excel support page does not say whether your data must be formatted as a table, how large a workbook can be, which functions are supported, or how to undo a Copilot change. So work on a copy. If Copilot refuses a big workbook, split the data or try a smaller range.

Check its work

  • Click into a few generated cells and read the formulas. Do they refer to the right ranges?
  • Spot-check one total by hand.
  • Be most careful when it filters or sorts. Make sure rows weren't dropped.

ChatWith Copilot Chat

If your Excel has no Copilot pane, you can still use Chat in the browser: paste a small table, or upload the file, and ask for a formula or an explanation. Chat does not change your workbook. Do not paste data your organisation does not allow you to share; see Safety.

Prompt · Chat
Here is a table of data: [paste it].
Write a formula for column [D] that [describes what it should calculate].
Explain it in one sentence, and tell me what happens if a cell in [B] is empty.
Prompt · Chat
Look at the pasted data. Tell me three things that stand out, and one thing that looks like an error or an outlier.
Explain how you know.

[Paste the data here]

PremiumWith M365 Copilot (Premium)

Copilot works inside the workbook, in the mode you choose, and can import data from other workbooks you can open. Pick the mode in the Copilot pane. Need a different kind of analysis? Look at the Analyst agent on its page.

Prompt · Premium, Chat only mode
Look at the data on this sheet. Tell me three things that stand out, and one thing that looks like an error or an outlier.
Explain how you know. Don't change anything.
Prompt · Premium, Plan mode
I want a summary table of [measure] by [category] and [month], plus a chart that shows the trend.
Show me your plan first. Use formulas, not pasted values, so the table updates when the data does.
