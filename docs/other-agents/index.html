Agents · Built by Microsoft

Other Microsoft agents

Besides Researcher and Analyst, Microsoft ships a handful of single-purpose agents.

The short version

  • Visual Creator is shown by default. The coaches are added from All agents.
  • Microsoft says "more agents are coming soon", so the list changes.
  • Availability varies by subscription and organisation settings.

What each one is for

AgentWhat it doesWhere
Visual CreatorTurns descriptions into visuals, prototypes, videos and interactive scenariosShown by default
Idea CoachGenerates and refines ideas into structured plansAdd via All agents
Writing CoachFeedback on tone, grammar and styleAdd via All agents
Prompt CoachTeaches you to structure promptsAdd via All agents
Learning CoachHelps master subjects and build study plansAdd via All agents
Career CoachSkills, goals and career planning; Microsoft's page mentions students and institutionsAdd via All agents

Newer items in Microsoft's release notes include a Learning Agent for Windows and a SharePoint list agent. Microsoft doesn't say whether the Learning Agent replaces Learning Coach.

One prompt each

Visual Creator
Create a simple visual that explains [idea] to [audience].
Style: clean and minimal, using [two colours]. Add a short caption.
Idea Coach
I need ideas for [goal]. Give me five, then help me pick one and turn it into a three-step plan with a first action for this week.
Writing Coach
Review the text below for tone, grammar and clarity for [audience].
Point out the three changes that would help most, and explain why.

[Paste the text here]
Prompt Coach
Here is a prompt I use: [paste it].
Improve it using goal, context, source and expectations, and explain each change.
Learning Coach
I want to learn [skill] in [four weeks], at [30 minutes a day]. Build me a study plan with a weekly goal and a short quiz at the end of each week.
Career Coach
My current role is [role]. I want to move towards [goal]. List the skills I should build, in order, and one small step for each.

ChatOn Copilot Chat

Microsoft's admin guide says the Idea, Writing, Prompt, Career and Learning coaches are included with Copilot Chat at no additional cost. Your organisation must have enabled the agent for you, and a Microsoft setup page suggests some use may be metered where pay-as-you-go is on. If a coach is in your All agents list, you can use it.

PremiumWith M365 Copilot (Premium)

You have the same Microsoft-built agents, plus Researcher and Analyst. Availability still depends on what your administrator has turned on.
