Agents · Safety

Using agents safely

Agents are Copilot with a narrower job. The same rules apply, plus a few of their own.

The short version

  • Agents see only what the person using them could already open.
  • Agents from other companies handle your data under their own privacy statements. Read it first.
  • Never put secrets or personal data in an agent's instructions or knowledge.
  • Retire agents you no longer use.

What each kind of agent can reach

KindWhat it can reach
Microsoft-built agentsDepend on the agent. Researcher uses the web and your work content within your permissions.
Agents you or a colleague builtTheir knowledge sources, filtered by the permissions of whoever is chatting.
Agents from partners or other companiesWhatever the administrator allowed. Copilot may send them a search query based on your prompt, your activity history and data you can access.

Encrypted content can exclude programmatic access, which can stop an agent reading it.

Third-party and organisation agents

  • Check the agent's privacy statement and terms before using it. Microsoft says these determine how your organisation's data is handled.
  • An agent builder can add their own privacy and terms links; the defaults are placeholders, so don't assume they've been filled in.
  • I couldn't find a Microsoft statement that third-party agents are covered by its "no training" commitments, so don't assume it.
  • Administrators decide which agents are allowed and can see their permissions. That is an organisation setting.

What not to put in instructions or knowledge

  • Passwords, keys, tokens or personal data.
  • Files you wouldn't want every user of the agent to see answers from. Anyone who can use the agent can see answers grounded in embedded files.
  • Whole mailboxes in a shared agent.
  • Anything your organisation classes as restricted.

Checking outputs

  • Ask for sources, then open them.
  • Test an agent with a question its sources can't answer. It should say so.
  • Treat answers about people, money and customers as drafts for a human to check.

Retiring agents you no longer use

  1. Remove people you shared it with. Removing someone from an agent does not remove their access to its files, so fix the file permissions too.
  2. Delete the agent. For Agent Builder agents this is permanent. For SharePoint agents, delete the .agent file.
  3. Unpin agents you no longer use from your Agents list.

ChatOn Copilot Chat

Agents with work data are off by default and billed by use. An administrator turns them on. If an agent says you can't use it, that is most likely a setting or a billing choice, not something you did.

PremiumWith M365 Copilot (Premium)

An agent built on your mailbox or meetings can surface sensitive material. Build shared agents on SharePoint sources, not on your email.
