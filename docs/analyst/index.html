Agents · Analyst

Analyst

Hand it data. Get back trends, charts and an explanation of how it got there.

The short version

  • Microsoft describes Analyst as turning raw data into insights and clear visualisations for metrics, trends and forecasts.
  • Always request its working, then check one number by hand.
  • Analyst is a licensed agent. I couldn't find a Microsoft page that gives it to Chat-only users.

What goes in, and what comes out

Give Analyst a data file or table and a question. It answers with findings and visualisations. Microsoft's page is a short description. I couldn't find a detailed Analyst page (the one I tried returned an error), so I can't tell you its file-size limits or supported formats. Test with a small, clean sample first.

Checking its calculations

  • Request an explanation of how Analyst calculated each figure and which columns it used.
  • Recalculate one total or average yourself.
  • Watch for rows dropped by a filter, and for dates read the wrong way round.
  • Don't forward a chart until you can say in one sentence what it shows.

Analyst or Copilot in Excel?

ChooseWhen
Copilot in ExcelYou want the workbook itself changed or built: formulas, PivotTables, charts that stay in the file. See Excel.
AnalystYou want questions answered about data and a quick set of insights, without editing a workbook.

This split is my rule of thumb, not a Microsoft statement.

ChatOn Copilot Chat

Microsoft's Support comparison lists Analyst under the advanced agents on the licensed side. If it isn't in your Agents pane, use ordinary chat: paste a small table and ask for trends and a formula, as in the Excel Chat section.

Prompt · Chat
Here is a table: [paste it].
What are the three biggest trends, and one number that doesn't fit?
Explain how you calculated each, and say what you could not tell from this data.

PremiumWith M365 Copilot (Premium)

Analyst is pinned by default where you have it. Open it from the Agents pane and attach your file.

Prompt · Premium
Here is my data: [attach file].
What are the three biggest trends, and one number that doesn't fit?
Show a chart for each trend and explain how you calculated it.
