Playbook

Make sense of a spreadsheet

Ask questions of the data first. Change the workbook second, on a copy.

ChatWith Copilot Chat

  1. Give it the dataUpload the file to Copilot Chat or paste a small table. Check what you may share first.
  2. Ask what stands outChat explains and writes formulas. It does not change your workbook.
  3. Copy the formula acrossPaste it into Excel and test it on a few rows.
  4. Have Copilot in Excel?If the button is there, use Chat only mode to explore safely.
Prompt · Chat
Here is a table of data:
[Paste the data here]
Tell me three things that stand out and one thing that looks like an error or an outlier. Explain how you know.
Then write a formula for column [D] that [describes what it should calculate], and explain it in one sentence.

PremiumWith M365 Copilot (Premium)

  1. Open Copilot in ExcelPick the mode before you ask: Chat only to explore, Plan to see changes first, Allow editing on a copy.
  2. Explore, then buildAsk what stands out. Then ask for the summary table or chart.
  3. Bigger question?Try the Analyst agent.
Prompt · Premium
Look at the data on this sheet. Tell me three things that stand out and one thing that looks like an error or an outlier.
Then show me your plan for a summary table of [measure] by [category] and [month], with a chart of the trend.
Use formulas, not pasted values. Do not change anything until I say so.

Push it further

The first answer is a draft. Send one of these next:

Follow-up
Explain this formula step by step: [Paste the formula here]
Follow-up
What happens to the result if a cell in column [B] is empty?
Follow-up
Which rows did you exclude, and why?

Before you use it

  • Click into the formulas. Do they point at the right ranges?
  • Recalculate one total by hand.
  • After a sort or filter, count the rows.
