Guide 2

Copilot Chat

The everyday chat. It is the one part of Copilot almost everyone at a Microsoft 365 company already has.

The short version

  • Open it at copilot.cloud.microsoft, in the Edge sidebar, or inside Outlook and Teams, signed in with your work account.
  • Without the paid licence it answers from the web. To use a work document you have to give it that document.
  • Check anything important. It can be wrong, and it can answer differently each time.

1Getting in

Copilot Chat is available to people who sign in with a Microsoft Entra work or school account on an eligible Microsoft 365 plan, at no extra cost (Microsoft, 2026e). You can reach it in several places:

  • The Microsoft Copilot app on web, desktop and mobile (copilot.cloud.microsoft)
  • The Copilot icon in the Edge sidebar, when Edge is signed in with your work account
  • Copilot Chat inside Outlook and Teams
Check which account you are in

The app also accepts personal Microsoft accounts. Chats, files and protections are kept separate for each. For work, look for the Work label under your profile and the green data protection shield (Microsoft, 2026e).

2Web data versus work data

Two kinds of information can feed an answer:

WebYour work data
What it isPublic information, found by sending a search query to Bing when Copilot decides it would helpYour emails, files, meetings, chats and calendar
Basic versionsYesOnly what you provide
PremiumYesYes, automatically

Your administrator can turn web search off with the Allow web search in Copilot policy. If they do, Copilot answers from the language model alone (Microsoft, 2026e).

3Giving it your files

If you do not have the Premium licence, Microsoft says there are three ways to get work content into Copilot Chat (Microsoft, 2026a):

  1. Paste or upload itCopy text into the prompt, upload a file, or select a file when you write the prompt.
  2. Open it firstIn Outlook and Teams, Copilot Chat can see the item you have open, so you do not need to paste it.
  3. Use an agentPay-as-you-go agents can reach organisational content. Your company has to have turned this on.

4Choosing how it thinks

Copilot has a model selector. The default is Auto, which picks for you (Microsoft, 2026a).

OptionUse it for
AutoMost of the time
Quick responseSimple questions where you want a short answer fast
Think deeperOpen-ended or complex questions where you would rather wait for a more thorough answer

Microsoft notes these options change as new models arrive. Your administrator decides whether models from outside providers, such as Anthropic and OpenAI, are available.

5Four habits that help

  1. Start with the goal. Add context, sources and the format you want only if you need them (Microsoft, 2026c).
  2. Follow up. Microsoft expects you to refine; the first answer is a draft.
  3. Check what matters. Microsoft says responses are not guaranteed to be fully factual and you should review them before sending them to others (Microsoft, 2026d).
  4. Run it twice if it matters. The same prompt can give different results because of built-in randomness (Microsoft, 2026c).

Ready-made starting points are in the prompt library.
