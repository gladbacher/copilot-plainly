Agents · Safety

Using agents safely

Agents are Copilot with a narrower job. The same rules apply, plus a few of their own.

The short version

  • Agents see only what the person using them could already open.
  • Agents from other companies handle your data under their own privacy statements. Read it first.
  • Never put secrets or personal data in an agent's instructions or knowledge.
  • Retire agents you no longer use.

What each kind of agent can reach

KindWhat it can reach
Microsoft-built agentsDepend on the agent. Researcher uses the web and your work content within your permissions (Microsoft, 2026m).
Agents you or a colleague builtTheir knowledge sources, filtered by the permissions of whoever is chatting (Microsoft, 2026ab).
Agents from partners or other companiesWhatever the administrator allowed. Copilot may send them a search query based on your prompt, your activity history and data you can access (Microsoft, 2026d).

Encrypted content can exclude programmatic access, which can stop an agent reading it (Microsoft, 2026d).

Third-party and organisation agents

  • Check the agent's privacy statement and terms before using it. Microsoft says these determine how your organisation's data is handled (Microsoft, 2026d).
  • An agent builder can add their own privacy and terms links; the defaults are placeholders, so don't assume they've been filled in (Microsoft, 2026ab).
  • Microsoft's "no training" commitments are about its own service. Don't assume they cover an agent built by another company.
  • Administrators decide which agents are allowed and can see their permissions (Microsoft, 2026d, 2026ad). That is an organisation setting.

What not to put in instructions or knowledge

  • Passwords, keys, tokens or personal data.
  • Files you wouldn't want every user of the agent to see answers from. Anyone who can use the agent can see answers grounded in embedded files (Microsoft, 2026aa).
  • Whole mailboxes in a shared agent.
  • Anything your organisation classes as restricted.

Checking outputs

  • Ask for sources, then open them.
  • Test an agent with a question its sources can't answer. It should say so.
  • Treat answers about people, money and customers as drafts for a human to check.

Retiring agents you no longer use

  1. Remove people you shared it with. Removing someone from an agent does not remove their access to its files (Microsoft, 2026y), so fix the file permissions too.
  2. Delete the agent. For Agent Builder agents this is permanent (Microsoft, 2026ab). For SharePoint agents, delete the .agent file (Microsoft, 2026ak).
  3. Unpin agents you no longer use from your Agents list.

ChatOn Copilot Chat

Agents with work data are off by default and billed by use. An administrator turns them on (Microsoft, 2026ah). If an agent says you can't use it, that is most likely a setting or a billing choice, not something you did.

PremiumWith M365 Copilot (Premium)

An agent built on your mailbox or meetings can surface sensitive material. Build shared agents on SharePoint sources, not on your email.
