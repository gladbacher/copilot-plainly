Other material used

  • Format inspiration: Guides for Humans, a set of plain-language Claude guides. No text is copied from it.
  • The April 2026 report about embedded Copilot for unlicensed users comes from university help pages and a secondary quote of a Message Center notice, found through web search. Microsoft's current documentation matches it for the Copilot Chat (Basic) label, but I could not find the original announcement on a Microsoft documentation page, so the guides present it as a report.
  • The troubleshooting steps marked Reported (updating a licence in File > Account and update channels) come from IT help pages and community threads, not Microsoft's documentation.

Before you rely on a number

Prices, promotions and feature names change often. Microsoft's pages above are the authority; if they disagree with this site, believe them, and please tell the author so it can be fixed.
