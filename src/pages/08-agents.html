Guide 7

Agents

An agent is Copilot set up for one kind of job. You pick it, then give it the task.

The short version

  • Microsoft ships a set of agents. Researcher and Analyst are the two most useful at work.
  • Researcher is slower on purpose and gives a cited report. Use normal chat for quick things.
  • Your company decides which agents exist for you. A missing one usually means licence or admin settings.

1What an agent is

Microsoft describes agents as scoped or focused versions of Copilot that act as assistants and can automate processes (Microsoft, 2026a). In the Copilot app you find them under Agents in Chat. Which ones you see depends on your subscription, and your administrator controls which agents are allowed (Microsoft, 2026d, 2026n).

2Researcher

Researcher handles complex, multi-step research. It draws on the web and your work content (files, emails, meetings and chats you can access) and produces a report with organised sections, cited sources and often charts. It follows the same permissions and policies as the rest of Copilot (Microsoft, 2026m).

You need…Choose
A quick summary, a short reply, light brainstormingStandard Copilot chat
Deeper reasoning across web and work sources, and a report you can shareResearcher
Citations and clean structure for a decisionResearcher
A back-and-forth without heavy analysisStandard Copilot chat

Source: Microsoft (2026m). Researcher deliberately spends longer retrieving and analysing.

Getting a better report

  • Be specific. Clear, detailed questions give more focused results.
  • Define the scope. Say whether you want work sources, the web, or both.
  • Answer its questions. It may ask clarifying questions first. That step steers the final report.
Prompt · Researcher
Research [topic] for a decision on [decision].
Scope: [the web only / our internal documents and emails only / both].
I need: the key findings, where sources disagree, risks, and a recommendation.
Cite every claim. Mark anything you could not verify.

3Analyst

Microsoft describes Analyst as turning raw data into insights and clear visualisations for business metrics, trends and forecasts (Microsoft, 2026n). For work inside a spreadsheet itself, see Excel.

Prompt · Analyst
Here is my data: [attach file].
What are the three biggest trends, and one number that doesn't fit?
Show a chart for each trend and explain how you calculated it.

5"I can't see an agent"

  • Microsoft says availability varies by subscription type. A missing agent can mean you lack a Copilot licence, or your administrator hasn't enabled it (Microsoft, 2026n).
  • With the Basic versions, agents grounded in instructions and public websites are included. Custom agents and agents that use work data are pay-as-you-go (Microsoft, 2026a).
Sources disagree on Researcher

One Microsoft Learn page says Researcher is part of the core experience for licensed users. A Microsoft Support page I found describes it as available to certain consumer subscribers. I couldn't settle this for a work account, so check with IT.

6Agents your company builds

Companies can build their own agents, for example for an HR or help-desk process, using tools such as Copilot Studio (Microsoft, 2026a). Before using one, read its privacy statement. Agents built by others handle your data under their own terms (Microsoft, 2026d). See Safety.

Sources: Microsoft (2026a, 2026d, 2026m, 2026n). Full details on the sources page.
