Beyond the chat box

Power features

The features most people never find. Several of them work on the free Copilot Chat licence.

The short version

  • Custom instructions and memory: tell Copilot once how you like things.
  • Pages: turn a good answer into a document you can edit and share.
  • Notebooks: gather the files for one piece of work and question them together.
  • Edge: summarise the web page or PDF in front of you.
  • Saved prompts: stop retyping. Premium can also run prompts on a schedule.

Microsoft is rolling out a new Copilot home screen, so a menu may sit in a slightly different place from the steps below. Your organisation can also switch any of these off.

Custom instructions: set it once

Custom instructions tell Copilot your preferences, and it applies them in future chats (Microsoft, 2026be).

  1. In Copilot Chat, select … Settings and more at the top right, then Chat settings.
  2. Choose Personalization, find Custom instructions and select Edit instructions.
  3. Write your preferences and select Save instructions.
Custom instructions to start from
I work as [role] in [team or industry]. Use UK spelling and plain words.
Lead with the answer, then the reasoning. Use short bullets for lists.
If you are not sure, say so. Never guess a number, a name or a date.

If the toggle is off and won't turn on, your organisation has switched personalisation off (Microsoft, 2026bh).

Memory: what Copilot keeps about you

  • With Copilot Memory on, Copilot saves key details from your chats, such as your style and recurring tasks. Microsoft says memory is available with and without a Copilot licence (Microsoft, 2026bd, 2026bh).
  • Ask "What do you know about me?" to see it. Delete memories in Chat settings (Microsoft, 2026bd).
  • For a chat you don't want remembered, select Start a new temporary chat at the top right. Your organisation's retention rules can still keep a copy (Microsoft, 2026bd).
  • Memories are stored in your mailbox and administrators can search them, like the rest of your Copilot history (Microsoft, 2026bh). See Safety.

Pages: keep and share a good answer

A Copilot Page turns a chat answer into content you can edit, refine with Copilot and work on with colleagues. Work accounts with SharePoint or OneDrive storage have it, including people without a Copilot licence (Microsoft, 2026ba).

  1. Under a Copilot answer, select the … menu, then Edit in Pages. Choose a new or existing page.
  2. The page opens beside the chat. Rename it, edit it, and keep asking Copilot to improve it.
  3. Share it with colleagues. Earlier pages are in the Copilot Library.

Use it whenever an answer is worth keeping: a draft, a plan, meeting notes, a comparison table.

Edge: summarise what is in front of you

Select the Copilot icon at the top right of Edge, signed in with your work account. Copilot Chat can summarise website content and some document types shown in Edge (Microsoft, 2026a).

Prompt · in Edge
Summarise this page for [who]. Give me the five points that matter, anything that looks out of date, and what I should read in full.

Saved prompts: stop retyping

After a prompt has run, hover over it and select the bookmark icon, Save prompt. It appears under Your saved prompts in the Copilot Prompt Lab, visible only to you (Microsoft, 2026bf). Microsoft's page doesn't state a licence for this, so look for the bookmark. If it isn't there, keep a "My prompts" note instead.

Images

Where your organisation allows image generation, ask for an image in Copilot Chat, or use the Visual Creator agent (Microsoft, 2026a, 2026n).

ChatNotebooks on Copilot Chat

A notebook gathers the files, pages and notes for one piece of work, so Copilot answers from all of them. Eligible Copilot Chat users get a streamlined version (Microsoft, 2026bb, 2026bc).

  1. Go to m365.cloud.microsoft and select Notebooks in the left menu, or find it in the app launcher.
  2. Select New notebook, name it, and add references: upload, drag and drop, or pick from OneDrive.
  3. Select Create, then ask questions across everything in it.
  • You get: up to 50 sources per notebook, plus mind maps, infographics, study guides, reports, flashcards and quizzes (Microsoft, 2026bb).
  • You can add: PDFs, text and media files, Word, Excel and PowerPoint files, OneNote and Loop pages, and email threads (Microsoft, 2026bb).
  • Not on Chat: web links, Teams chats and meetings as sources, suggested references, Audio Overviews, and Researcher inside a notebook (Microsoft, 2026bb).

If Notebooks is missing or shows a licence message, it is not switched on for you. Uploading the files to an ordinary chat is the fallback.

Scheduled prompts need a Copilot licence, so they are not on this track (Microsoft, 2026bg).

PremiumNotebooks, scheduling and search on Premium

Notebooks, in full

Create one the same way: m365.cloud.microsoft, Notebooks, New notebook, add references, Create (Microsoft, 2026bc). With a licence you get (Microsoft, 2026bb):

  • Up to 300 sources per notebook, with suggested references.
  • Web links, Teams chats, meetings, and SharePoint and OneDrive content as sources.
  • Researcher inside the notebook, up to 25 a month.
  • Audio Overviews, up to 20 a day, and Live Capture.
  • A Word, Excel or PowerPoint document created from the notebook in one go.

Scheduled prompts

Have a prompt run by itself, for example a Monday summary of what needs your attention (Microsoft, 2026bg).

  1. In Copilot Chat, hover over a prompt you have sent and select Schedule this prompt.
  2. Choose when and how often, and whether to get an email when it is ready. Select Save.
  3. Manage them under … Settings and more, then Scheduled prompts. You can have up to 10.
Prompt · worth scheduling
Summarise what needs my attention this week from my emails, meetings and chats.
List deadlines, things waiting on me, and meetings I should prepare for. Name the source of each.

Copilot Search

Copilot Search is one search across your Microsoft 365 apps and connected sources. Microsoft lists it with the Premium licence (Microsoft, 2026a).
