## Excel (S9)
Can edit worksheets, generate data/formulas, charts, PivotTables, sort/filter, web search with citations, import from other workbooks, run saved "skills". Content stays editable. Three modes: Allow editing (default, multi-step edits), Plan (proposes plan to review before changes), Chat only (no changes). Stop button. Platforms: Windows/Mac/web edit+chat+plan; iPad chat+plan (edit rolling out); iPhone and Android chat only. Needs eligible Copilot licence + org settings. Page does NOT state: table requirement, size limits, supported functions, undo behaviour. (Page doesn't use "Agent mode" term.)

## Word (S10)
Draft from request/outline/notes/files; reuse template formatting; add sections/tables; edit in place; rewrite selected text (tone, shorten); citations. Start: cursor in doc, Copilot bottom-right, describe topic/audience/tone/format/length, optionally "/" to pick a file source, Generate; keep/discard/regenerate/refine. Requires eligible subscription and/or Copilot licence; features roll out gradually by licence/org/app version/platform. Model choice depends on subscription (Auto, Instant, Think deeper for users without custom selection). Output is a draft: check facts, numbers, citations, names, policy statements. Applies the document's sensitivity label.

## PowerPoint (S11)
Draft from prompt or referenced file (Word docs pull structure + images). Start in PowerPoint: Copilot icon > Add Content > Agent Mode > prompt; may ask clarifying questions (audience, style) and build an outline first. On the web: sign in at m365.cloud.microsoft with work account; saves to OneDrive and gives a link. Needs Copilot licence + org settings. Word-based decks: works best with files under 24 MB; start from org template. Limits: one output language at a time; from a file you can't add extra context in same prompt; you need permission on referenced files; referencing files in Agent Mode "coming soon"; length/tone/style/image controls rolling out to Frontier/Insiders first. AI images noted as AI-generated in speaker notes. Review output.

## Outlook (S12)
Copilot Chat in Outlook (Outlook for M365, Mac, New Outlook for Windows; classic Outlook not mentioned). Sign in with work account, click Copilot button. WITHOUT add-on licence: ask about inbox, calendar, meetings, limited data; summarise emails, check meeting times, draft emails, schedule meetings, flag emails, set automatic replies. WITH add-on: plus chats and enterprise data (documents) e.g. prioritise unread email, draft agendas/pre-reads.

## Agents
- Researcher (S13): multi-step research; web + your work content (files, emails, meetings, chats you can access); cited reports with visuals; respects same permissions. Find under Agents in Chat. Tips: be specific, define scope (work, web, or both), answer its clarifying questions. Slower by design. Typical time (<5 min simple, 10-45 min complex) is from search-result snippet of Learn FAQ, NOT verified on page: omit or flag.
